# Требования к работе над Career Quest

Основание: предоставленные пользователем документы «Инструкция для участников
HackAlem AI» и «Правила зачета участия». Это краткая рабочая памятка,
а не замена оригинальных правил организаторов.

## Разработка и проверка

- Работать над выбранным кейсом Career Quest, сверять обязательные функции
  с полным описанием кейса и критериями оценивания.
- Использовать AI-агента при разработке; Codex уже используется в этой работе.
- Организаторы отводят на реализацию обязательных требований 5 часов.
  Время старта и дедлайн этой команды в проекте не зафиксированы.
- Проверять основной сценарий от входных данных до результата.
- Поддерживать README на русском: задача и аудитория, реализованные функции,
  сценарий, технологии и архитектура, установка и запуск, воспроизводимая проверка,
  данные и сервисы, ограничения, ссылка на развёрнутую версию при её наличии.
- Описывать только подтверждённые функции и результаты. Не выдавать демоданные
  за датасет организаторов или переключатель HR за разграничение доступа.
- Не публиковать API-ключи. Инструкция отдельно отсылает к документу активации
  Codex, OpenAI API и NVIDIA; этот документ не предоставлен. Использование всех
  этих API внутри приложения из прочитанных правил не следует.
- Ограничение пользователя для кейса: не выносить датасет за пределы хакатона.
  Реальные данные не добавлять в Git, внешние сервисы или облачную синхронизацию.

## Перед сдачей

1. Сверить решение с полным текстом кейса и прогнать основной сценарий и тесты.
2. Обновить README, проверить отсутствие секретов и запрещённых к публикации данных.
3. По поручению команды отправить финальный код в выданный платформой репозиторий
   `BAITC-Hacks/hack-b18d812e-mcqueen`.
4. На странице треков выбрать кейс, нажать «Сдать решение», заполнить название
   и описание. По инструкции решение можно обновлять до дедлайна.

Эта памятка не означает, что публикация или сдача уже выполнены, и сама по себе
не является поручением агенту выполнить внешние действия.

## Обязанности участников

Каждый участник должен внести личный вклад; проект создаётся в рамках хакатона.
Стюарды и свидетели не участвуют в разработке. По техническим вопросам участник
обращается к ментору, подняв руку.

Правила также требуют личного бейджа и сканирования входов/выходов, возвращения
до старта, сохранения места и сектора после старта, согласования выходов со стюардом.
Личные выходы ограничены суммарно 60 минутами. Последний час необходимо находиться
на площадке; экстренный выход до 5 минут возможен только с разрешения стюарда.
Нельзя уходить до официального завершения. Нарушения могут привести к незачёту
участия или дисквалификации. Соблюдение этих условий контролируют участники
и организаторы, приложение его не подтверждает.
