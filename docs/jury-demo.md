# Самостоятельная проверка Career Quest для жюри

Решение сдаётся через репозиторий команды. Приложение запускается локально на
компьютере проверяющего; публичного сайта нет.

## Запуск

1. Скачайте свежую копию репозитория. Требуется Node.js 20+.
2. В Windows откройте `start.cmd`, либо выполните `node server.js` в папке проекта.
3. Откройте `http://localhost:3000`. Если задан `PORT`, используйте его значение.
4. В терминале показаны логин `hr` и код доступа. Не публикуйте код.
5. Без стартового кита загрузится `demo.json` с тремя вымышленными сотрудниками.
   Внешние API и установка пакетов не нужны.

Адрес localhost относится к тому компьютеру, на котором открыт браузер.
Для повторной проверки с нуля можно указать новую папку `CAREER_QUEST_STORAGE`.
Импорт кита описан в README; локальные данные и файлы доступа в Git не включены.

## Что проверить

- У «Демо: Алия» начальное покрытие требований Middle — 38%.
- Обоснование «Практикума Python»: текущий уровень 1, требуется 3, прирост +2.
- Выбор задачи не меняет навыки. Завершение практикума даёт покрытие 63%.
- После SQL покрытие — 88%, появляется дальнейшая цель Senior.
- После «Демо для команды» текущая цель выполнена на 100%; фактический грейд
  автоматически не повышается.
- После завершения появляется карточка «Выполнено» с названием и датой.
  Кнопка «Посмотреть историю» открывает сохранённые результаты.
- При 0–1 рекомендации система предлагает самостоятельную практику, если есть
  незакрытые дефициты. Завершение — одним нажатием, без опроса и обязательного текста.
  Запись сохраняется после перезапуска, повторное завершение отклоняется.
- HR видит дефициты компетенций, отсутствие шагов и участие в программах.
- HR может выдать код сотруднику; после входа с ним доступен только свой профиль.

## AI-слой и ограничения

Рекомендации учитывают карьерную цель, разрывы навыков, доступность активностей
и историю. Локальная байесовская модель оценивает вероятность завершения;
это прогноз, а не гарантия повышения. Обоснования связаны с факторами расчёта.
LLM и внешние AI API не подключены. Самостоятельная практика основана на шаблонах
и не повышает подтверждённые навыки. Завершение курса моделируется кнопкой;
подтверждение наставником пока не реализовано.

Для проверки качества разберите рекомендации 3–5 профилей из разрешённого набора:
цель → дефицит → доступность → ожидаемый прирост → обоснование.
Автоматические проверки запускаются командой `node --test`; качество на закрытых
профилях жюри ещё предстоит оценить.
